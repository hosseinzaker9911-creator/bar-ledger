دفتر خرید و تحویل بار - نسخه قابل نصب (PWA)

این پوشه را روی یک هاست با HTTPS منتشر کنید (مثلاً Netlify Drop یا GitHub Pages).
سپس آدرس را در موبایل باز کنید:

اندروید (Chrome): منوی سه‌نقطه > نصب برنامه (Install app)
آیفون (Safari): دکمه اشتراک‌گذاری > افزودن به صفحه اصلی (Add to Home Screen)

فایل‌ها:
- index.html      صفحه اصلی برنامه
- manifest.webmanifest   نام، آیکون و رنگ برنامه
- sw.js           کار کردن آفلاین
- icons/          آیکون‌ها
