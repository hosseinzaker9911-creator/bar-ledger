# دفتر معاملات بشکه (Barrel Ledger)

اپلیکیشن ثبت صوتی معاملات بشکه و لیتر، با ویرایش، تاریخچه تغییرات، قفل رکورد، سطل زباله و سیستم لایسنس.
این نسخه یک **PWA** است: روی Android و iPhone از مرورگر نصب می‌شود (Chrome: «افزودن به صفحه اصلی»، Safari: Share → Add to Home Screen) و نیازی به حساب Google Play یا App Store ندارد.

## ساختار

| مسیر | کار |
|---|---|
| `src/units.js` | تبدیل بشکه و لیتر (۱ بشکه = ۲۲۰ لیتر)، اعداد فارسی |
| `src/spoken-numbers.js` | تبدیل عدد گفتاری فارسی («بیست و سه»، «دو هزار و پانصد») |
| `src/voice-parser.js` | تحلیل جمله صوتی/تایپی به فیلدها؛ ابهام را گزارش می‌کند و حدس نمی‌زند |
| `src/calc.js` | محاسبات مشتق‌شده (اختلاف، مبلغ خرید/فروش، سود، مانده) |
| `src/store.js` | رکورد، تاریخچه تغییرات (Audit)، قفل، سطل زباله، لغو و بازگردانی |
| `src/crypto.js` | رمزنگاری داده روی دستگاه (PBKDF2 + AES-GCM) |
| `src/license.js` | بررسی توکن امضاشده لایسنس (ECDSA P-256) روی دستگاه |
| `src/render.js`, `src/jalali.js` | قالب‌های HTML (با escape) و تاریخ شمسی |
| `app.js`, `index.html`, `styles.css` | رابط کاربری |
| `server/license-server.mjs` | سرور فعال‌سازی و ابزار مدیریت لایسنس (CLI) |
| `test/` | ۵۵ آزمون واحد و یکپارچه (`npm test`) |

## اجرای تست‌ها

```bash
npm test
```

## نصب روی گوشی (برای کاربر نهایی)

1. آدرس HTTPS برنامه را در مرورگر باز کنید (Android: Chrome، iPhone: Safari).
2. Android: منوی Chrome ← «Install app» یا «افزودن به صفحه اصلی».
   iPhone: دکمه Share ← «Add to Home Screen».
3. برنامه را از صفحه اصلی گوشی باز کنید، رمز برنامه را بسازید، سپس کلید فعال‌سازی را وارد کنید.

## راه‌اندازی برای مالک (یک بار)

کلید عمومی مجوز از قبل در `config.js` قرار داده شده است. کلید خصوصی در فایل جداگانه‌ای تحویل داده شده و **فقط** باید روی سرور لایسنس باشد. آن را در برنامه، در ایمیل یا در مخزن کد قرار ندهید.

1. **میزبانی فایل‌های برنامه** (`barrel-ledger-web.zip`) روی یک میزبان استاتیک با **HTTPS**. بدون HTTPS میکروفون، رمزنگاری و نصب برنامه کار نمی‌کند.
2. **اجرای سرور لایسنس** روی یک سرور با HTTPS و Node.js نسخه ۲۲ یا بالاتر:
   ```bash
   LICENSE_PRIVATE_KEY_JWK='<کلید خصوصی>' LICENSE_ALLOWED_ORIGIN='https://آدرس-برنامه' \
     node server/license-server.mjs serve 8787
   ```
3. **تنظیم آدرس سرور** در `config.js` ← `LICENSE_ENDPOINT` (مثلاً `https://license.yourdomain.ir/api/activate`)، قبل از آپلود فایل‌ها.
4. **صدور لایسنس** برای هر مشتری:
   ```bash
   node server/license-server.mjs add KEY-123 365 1   # کلید، روز اعتبار، تعداد دستگاه
   node server/license-server.mjs revoke KEY-123      # غیرفعال‌سازی
   node server/license-server.mjs release KEY-123 DEVICE_ID   # آزادسازی یک دستگاه
   ```
5. از فایل `licenses.json` سرور **پشتیبان** بگیرید.

برای آزمایش محلی: `python3 -m http.server 8080` در پوشه برنامه و باز کردن `http://localhost:8080` (localhost استثنای HTTPS است).

## رفتار امنیتی لایسنس

- نصب یا کپی کردن برنامه به‌تنهایی کافی نیست: بدون توکن معتبر برای همان دستگاه، برنامه پیام «این برنامه نیاز به مجوز معتبر دارد» می‌دهد.
- توکن با کلید خصوصی سرور امضا می‌شود؛ تغییر دادن آن در دستگاه قابل تشخیص است.
- توکن برای یک دستگاه صادر می‌شود و روی دستگاه دیگر کار نمی‌کند.
- توکن حداکثر ۷ روز برای استفاده آفلاین معتبر است، سپس باید دوباره فعال‌سازی شود.
- هیچ سیستم موبایلی کاملاً غیرقابل‌کپی نیست. این طراحی کپی بدون مجوز معتبر را بی‌فایده می‌کند، اما صفر کردن خطر غیرممکن است.

## محدودیت‌های فعلی

- **تشخیص صوت** از Web Speech API با زبان `fa-IR` استفاده می‌کند. کیفیت آن بسته به مرورگر و دستگاه متفاوت است و روی iPhone باید آزمایش شود. در مرورگرهای بدون پشتیبانی، ورود متنی فعال است.
- **نقش مدیر** روی دستگاه فعال نیست. قفل کردن و لغو قفل در لایه داده اعمال می‌شود، اما رابط مدیر باید در پنل وب سرور ساخته شود (در این نسخه ساخته نشده است).
- **همگام‌سازی بین دستگاه‌ها** و حل تعارض ساخته نشده است. داده فعلاً روی همان دستگاه ذخیره می‌شود.
- **تفسیر عدد گفتاری** بخش‌های رایج زبان محاوره را پوشش می‌دهد، اما گرامر کامل فارسی نیست. جمله‌های مبهم به کاربر برای تأیید برمی‌گردند.
- **پیش‌فرض‌های محاسباتی**: سود بر اساس بار برای خرید و تحویل برای فروش محاسبه می‌شود. مانده = واریزی − مبلغ فروش. هر دو در `src/calc.js` قابل تغییرند؛ قبل از انتشار با مالک تأیید شوند.
- **به‌روزرسانی Service Worker**: با تغییر فایل‌ها، مقدار `CACHE` در `sw.js` را افزایش دهید تا نسخه جدید برای کاربران فعال شود.
- **انتشار در فروشگاه**: اگر بعداً نسخه فروشگاهی لازم شد، همین کدبیس را می‌توان با Capacitor بسته‌بندی کرد. آن مرحله به حساب توسعه‌دهنده Apple/Google نیاز دارد که برای کاربران ایرانی ممکن است محدود باشد.
